# 制造运营系统 - 部署与使用文档

## 1. 系统概述

本系统是基于《制造运营系统规划方案》设计的全栈制造执行/企业资源规划系统，覆盖销售管理、库存管理、仓库管理、发运管理、采购管理、计划排程、制造执行、质量管控、业务分析、人力分析、文控体系、资产管理等核心业务域。

### 1.1 技术栈

| 层级 | 技术 |
|------|------|
| 后端框架 | Spring Boot 3.2.5 |
| ORM | MyBatis-Plus 3.5.5 |
| 安全认证 | Spring Security + JWT (jjwt 0.12.5) |
| 数据库 | H2（开发模式，内存数据库） / MySQL 8.0+（生产模式） |
| 工具库 | Hutool 5.8.27、Lombok |
| 前端框架 | Vue 3.4 + TypeScript |
| UI组件库 | Element Plus 2.7 |
| 图表库 | ECharts 5.5 |
| 状态管理 | Pinia 2.1 |
| 构建工具 | Vite 5.3 |
| HTTP客户端 | Axios 1.7 |

## 3. 部署指南

### 3.1 开发模式部署（H2内存数据库）

此模式无需安装MySQL，开箱即用，适合快速预览和开发调试。

#### 3.1.1 后端启动

```bash
# 进入后端目录
cd backend

# 编译
mvn compile

# 启动服务
mvn spring-boot:run
```

后端启动成功标志：
```
Tomcat started on port 8080 (http) with context path '/api'
Started MesApplication in 2.672 seconds
```

#### 3.1.2 前端启动

```bash
# 进入前端目录
cd frontend

# 安装依赖（首次）
npm install

# 启动开发服务器
npm run dev
```

前端启动成功标志：
```
VITE v5.4.21  ready in 522 ms
➜  Local:   http://localhost:5173/
```

#### 3.1.3 访问系统

- 前端页面：http://localhost:5173/
- 后端API：http://localhost:8080/api
- H2数据库控制台：http://localhost:8080/api/h2-console
  - JDBC URL: `jdbc:h2:mem:mes_db`
  - 用户名：`sa`
  - 密码：空

### 3.2 生产模式部署（MySQL数据库）

#### 3.2.1 数据库初始化

```bash
# 登录MySQL
mysql -u root -p

# 执行建表脚本
mysql -u root -p < backend/src/main/resources/schema.sql
```

#### 3.2.2 修改后端配置

编辑 `backend/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/mes_db?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: root
    password: <你的数据库密码>
  sql:
    init:
      mode: never   # 生产环境关闭自动建表
```

#### 3.2.3 构建打包

```bash
# 后端打包
cd backend
mvn clean package -DskipTests
# 产物：target/mes-backend-1.0.0.jar

# 前端打包
cd frontend
npm run build
# 产物：dist/ 目录
```

#### 3.2.4 部署运行

```bash
# 后端
java -jar backend/target/mes-backend-1.0.0.jar

# 前端（Nginx配置示例）
# 将 frontend/dist/ 目录内容部署到Nginx
# nginx.conf 关键配置：
# location /api {
#     proxy_pass http://localhost:8080;
# }
# location / {
#     root /path/to/dist;
#     try_files $uri $uri/ /index.html;
# }
```

## 7. 架构设计说明

### 7.1 后端分层架构

```
Controller 层（REST API）
    ↓
Service 层（业务逻辑，继承 BaseService）
    ↓
Mapper 层（数据访问，继承 BaseMapper）
    ↓
Entity 层（数据实体，继承 BaseEntity）
```

**通用基类设计：**
- `BaseEntity`：提供 id、createTime、updateTime、createBy、updateBy、deleted 公共字段
- `BaseService<M, T>`：提供 page、list、getById、save、update、delete 通用方法
- `BaseController<S, T>`：提供标准 CRUD REST 接口

新增一个业务实体只需4步：
1. 创建 Entity（继承 BaseEntity）
2. 创建 Mapper（继承 BaseMapper）
3. 创建 Service（继承 BaseService）
4. 创建 Controller（继承 BaseController）

### 7.2 前端架构

```
Vue Router（路由 + 权限守卫）
    ↓
Layout（主布局：侧边栏 + 顶栏）
    ↓
Views（页面组件）
    ↓
Components（通用组件：CrudTable）
    ↓
API层（Axios封装 + 接口定义）
    ↓
Store（Pinia状态管理）
```

**通用表格组件 `CrudTable.vue`：**
- 通过 props 传入标题、API路径、列配置
- 自动实现分页查询、搜索、新增、编辑、删除
- 业务页面只需定义列配置即可获得完整CRUD功能

### 7.3 安全机制

- JWT无状态认证
- BCrypt密码加密
- 请求头 `Authorization: Bearer <token>` 携带Token
- 全局异常处理（401未登录、403无权限、400参数校验）
- CORS跨域支持
- 逻辑删除（deleted字段标记）

## 8. 常见问题

### Q1: 忘记密码怎么办？
A: H2模式下可重启服务（内存数据库会重置），或通过H2控制台直接修改数据库。MySQL模式下执行：
```sql
UPDATE sys_user SET password = '$2a$10$7JB720yubVSZvUI0rEqK/.VqGOZTH.ulu33dHOiBE8ByOhJIrdAu2' WHERE username = 'admin';
-- 重置后密码为 admin123
```

### Q2: 切换到MySQL数据库后启动报错？
A: 检查 `application.yml` 中数据库连接配置是否正确，确保MySQL服务已启动，数据库已创建。

### Q3: 前端页面空白？
A: 检查后端服务是否正常启动（8080端口），查看浏览器控制台是否有跨域错误。Vite已配置代理 `/api -> http://localhost:8080`。

### Q4: 如何新增一个业务模块？
A: 参照架构设计说明，4步即可完成后端，前端创建一个Vue页面使用CrudTable组件即可。

### Q5: H2数据库数据丢失？
A: H2为内存数据库，重启后数据重置。如需保留数据，切换为MySQL模式或使用H2文件模式（修改JDBC URL为 `jdbc:h2:file:./data/mes_db`）。
